## Evidentiary posture
This is AI-assisted, source-linked citizen research. It is not a judicial finding, government audit, legal opinion, or political endorsement. Financial deterioration, corporate authority, property/licensing authority, the disputed employment sequence, and political-message sponsorship are separate questions and are not forced into one conclusion.

The current collected-record cutoff is September 28, 2026, before the evening City Council meeting. Later records should be added as dated updates.

## Reproduce calculations
```bash
python scripts/reconcile.py --out data/reconciliation_results.json
```

Passing arithmetic verifies the calculation, not the underlying alleged transaction.
